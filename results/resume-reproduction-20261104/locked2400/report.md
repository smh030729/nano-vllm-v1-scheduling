# Nano-vLLM 三项优化：RTX 4070 Ti SUPER 本机复现

日期：2026-11-04。模型：Qwen3-0.6B，BF16，单 GPU。Graphics/SM 锁定 2400 MHz；显存未单独锁频。

比较对象是当前源码和朋友提供的原始/优化源码。朋友使用 RTX 5080；本报告比较优化方向及比例，不比较两张 GPU 的绝对吞吐。

缓存与调度依据已提供源码；CUDA 融合使用本次实现。未在已提供目录发现朋友完整的融合 benchmark 脚本，因此下面六种端到端负载由本地设计，不宣称逐项复刻他的六组负载。当前融合接入 Prefill 和 Decode，朋友简历强调 Decode 接入。

## 实验方法

- 调度：原始 upstream → 当前统一调度/异步 auto；另测已支持混合 batch 的冻结旧版、以及全部优化。每组 ABBA 四个独立进程，每进程预热后测三次，每侧六条观测。
- 缓存原方案：原始 upstream → 独立 queue-aware-cache（前瞻 16、uncached-first、侵入式链表），六对独立进程，每进程预热后测一次；配对顺序交替 AB/BA。
- 缓存整合方案：同一统一调度/异步 auto 引擎内，缓存关闭/开启/全部优化，ABCCBA 六个进程，每进程三次。
- 融合端到端：同一统一调度/异步 auto 引擎仅改变 CUDA 融合开关，十对独立进程，每进程六种负载、每种预热后测三次。每次重建空缓存元数据，避免重复调用的前缀命中污染。
- 融合微基准：每张 CUDA Graph 含 100 次前处理，计时 100 次 replay，十轮正反序配对；CUDA Event 记录 GPU 时间，减少 Python replay 发射间隔的影响。十轮在一个进程内，并非十对独立进程。
- 端到端使用真实采样、固定输出长度、ignore_eos；计时边界同步，不逐 token 读取 logits，不含模型加载、编译和 Graph capture。测试保留接收输出时间及执行计数。
- 下表为观测中位数之比。小幅收益额外给出独立进程配对统计，不直接视为普遍收益。

## 验证、频率和原始数据

- Budget 512 / integrated：32 行完整 logits，2 行逐位一致，最大绝对误差 0.1875，最大相对 L2 0.0178372，argmax 一致 31 行。
- Budget 512 / combined：32 行完整 logits，1 行逐位一致，最大绝对误差 0.1875，最大相对 L2 0.0272407，argmax 一致 32 行。
- Budget 1024 / integrated：32 行完整 logits，16 行逐位一致，最大绝对误差 0.1875，最大相对 L2 0.023205，argmax 一致 31 行。
- Budget 1024 / combined：32 行完整 logits，8 行逐位一致，最大绝对误差 0.1875，最大相对 L2 0.0272407，argmax 一致 31 行。
- 仅切换融合，Budget 512 / integrated → fusion_only：2/32 行逐位一致，最大相对 L2 2.767%，argmax 一致 31 行。
- 仅切换融合，Budget 1024 / integrated → fusion_only：8/32 行逐位一致，最大相对 L2 2.724%，argmax 一致 32 行。

**数值结论：** 这里通过的是原调度项目采用的相对 L2 ≤3% 门槛，不是逐位一致门槛。扩展负载不能沿用先前四个冷请求位置逐位一致的结论，也未复现朋友简历的 1,568-step 一致性验收。
融合性能对照的 180 组匹配观测中，40 组的全部请求生成历史逐 token 相同。各组输入、输出数量和 Prefill 计算量均匹配，但随机采样历史不同；性能测试不作为生成一致性证明。
独立审计确认 120 对调度观测的 Prefill/Decode 计算量及输出数量相同，六对缓存观测使用同一 trace，测量前后源码 SHA256 未变。

- GPU 遥测共 2154 条：SM/Graphics 实测范围 2400–2400 MHz；温度 34.0–64.6 °C。
- `environment.json` 保存包版本、全部进程参数和源码 SHA256；`extension-plan.json` 保存融合追加进程。
- `summary.json` 包含中位数及最小/最大范围；每进程 JSON 包含逐请求输出时间、计算 token 数、Graph 执行次数，日志保留警告。
- 先前已通过 268 项回归测试与六组整合正确性检查。本轮增加了两种预算的教师强制数值对照。
- 在用 KV blocks 峰值不等于进程显存；KV tensors 在初始化时预分配。
- 本轮为 Windows/WSL 本机离线请求流，包含 Python 调度、输入准备与结果回收，不包含 HTTP/网络延迟。

## 重跑

以下重跑主矩阵（39 个进程，其中融合端到端为两对进程）：

```bash
source /home/smh/ai_infra/nano-vllm/.venv/bin/activate
export PATH=/usr/local/cuda/bin:$PATH
python scripts/run_resume_reproduction.py --output /new/output/path
```
